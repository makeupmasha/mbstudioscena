# Изображения Sofi Leroux

София Леру — полностью вымышленная героиня около 30 лет. Три изображения
сгенерированы для этой демонстрационной копии 21 сентября 2026 года.
Фотографии исходного владельца использовались для изучения стиля, но не
входят в этот пакет. Владелец сможет заменить изображения через кабинет.

Краткие задания для генерации:

1. `media/demo/portrait.png`: светловолосая женщина около 30 лет, выразительный
   профессиональный beauty-макияж, кремовая блуза, мягкий студийный свет.
2. `media/demo/model-black.png`: та же героиня в чёрном закрытом couture-образе,
   полный рост, драматический круг света, fashion-редакционная съёмка.
3. `media/demo/studio.png`: та же героиня как визажист и владелица студии,
   кремовый костюм, застёгнутая рубашка, рабочее место с косметикой.

`model-white.png` повторяет третий снимок для совместимости с подборкой.
Старые резервные фотографии, слайды и портрет визитки также заменены.
При сборке изображения сайта преобразуются в WebP с ограничением 1600 px.

Ни профессиональный опыт, ни услуги, ни цены этой героини не являются
утверждениями о реальном специалисте; в публичном подвале и визитке есть
соответствующее пояснение.
